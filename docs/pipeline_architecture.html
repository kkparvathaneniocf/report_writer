Lab Report Pipeline Architecture

How PDFs from a TR folder become a filled DNV test report in Word, which parts are plain code, where Gemma is allowed to act, and how every value stays traceable to a spot in a source PDF.

Runs on the workstationGemma 4 through Ollama on localhost. No document leaves the machine.
Numbers never come from the modelTables and statistics are parsed and computed in code.
Every value cites a blockPage, line, cell, image or figure, with its bounding box.
A person signsManual fields stay manual; flagged values are reviewed first.
1

The system in one picture

The pipeline is a fixed sequence, run by run_pipeline(). Configuration says what to fetch; code decides how. The model is one tool inside the extract step, not the orchestrator.

2

Aimed retrieval, not search over everything

A report template is a fixed list of blanks, and the lab already knows which document answers each one. So the spec maps each blank to a document type, and retrieval is a filter, not a similarity search. The model sees one drawer, and its answer is checked against the exact blocks it names.

3

How the AI step works

The workflow is an orchestrated pipeline with one bounded model call per free-text field, which keeps the run reproducible and auditable. The model does not choose tools, loop, or write numbers. It answers one question, in JSON, and must name the blocks it read.

4

The trace chain

Traceability is a chain of ids that never breaks. Starting from a value in Word, each hop is a lookup, ending at the bytes of the source PDF.

5

How a status is decided

StatusRuleIn Word
VERIFIEDFound by code, exactly one value, and the value appears in the cited block text. Pictures: exactly one candidate matched.No highlight
COMPUTEDStatistics, joins or formats whose inputs are all VERIFIED. The record lists every input slot.No highlight
NEEDS_REVIEWAny model output; a copied value not found in its cited text; several matching pictures.Turquoise
CONFLICTTwo values within one document, or a cross-check source disagrees (COA vs infusion report).Pink
MISSINGLabel, table or picture not found; model disabled, empty or unparsable; any input of a calculation missing.Red
NOT_IMPLEMENTEDSlot exists in the template but has no method yet (Rk values).Red

A computed value takes the worst status of its inputs, so one conflicting cell marks the average as conflicting too.

6

Where to change things

Add a field

Add a slot to config/report_spec.yaml and a {{slot}} token in the template. No code change for label, table, statistics or image methods.

Add a test type

Add a document type rule, a results table entry with its columns, a stats entry and the template section. Comment #6 in the template defines which properties each test reports.

Real machine reports

Collect sample PDFs per instrument. If label and table matching are not enough for a layout, add a parser method in extract.py that still returns block ids.

Scanned PDFs

Pages without text need OCR or Gemma's image input in the index step, producing line blocks with boxes so the rest of the chain stays the same.

Another model

Pass --model. Anything implementing answer(system, prompt) -> JSON can replace OllamaClient; tests use a fake one.

# config/report_spec.yaml (excerpt)
fields:
  fabric_batch: {method: kv, source: COA, label: "Batch N°",
                 cross_check: [{source: INFUSION, label: Fabric batch}]}
  product_description: {method: llm, source: TR_REQUEST, instruction: "One sentence ..."}
images:
  tensile_curves: {method: figure, source: MACHINE_TENSILE, caption: Stress-strain curves}
7

Known limits

  • Tested only on generated dummy PDFs. Real layouts will need tuning of labels, table headers and captions.
  • Gemma is tested here with a fake client; the real model has to be checked on the workstation.
  • Rk characteristic values need the DNVGL-ST-0376 and GL2010 factors confirmed by the lab.
  • CV is shown in percent; the template example looks like a fraction. Needs a decision.
  • Template mapping in template_builder.py uses table order; a changed template means updating it.
